# mds_project_2026

## Min ML Service

---

### О проекте

Улучшенная версия семинарского проекта. Реализован полноценный ML-сервис с возможностью выбора моделей, динамическими параметрами и сохранением истории.

#### Что было добавлено относительно исходного проекта с пар:

- Выбор моделей (`LogisticRegression`, `RandomForestClassifier`)
- Динамические гиперпараметры на фронтенде в зависимости от выбранной модели
- Расширенное сохранение результатов в SQLite (модель, параметры, датасет, accuracy, timestamp)
- Загрузка пользовательских датасетов
- Улучшенный Streamlit интерфейс
- Docker + docker-compose

---

### Технологии

- **Backend**: FastAPI + Pydantic
- **Frontend**: Streamlit
- **ML**: scikit-learn
- **БД**: SQLite
- **Контейнеризация**: Docker Compose
