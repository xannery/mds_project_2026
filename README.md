# mds_project_2026

## Min ML Service

---

### О проекте

Улучшенная версия семинарского проекта. Реализован полноценный ML-сервис с возможностью выбора моделей, динамическими параметрами и сохранением истории.

#### Что было добавлено относительно исходного проекта с пар:

- Добавлен выбор моделей (`Logistic Regression` + `Random Forest`)
- Динамические гиперпараметры на фронтенде в зависимости от модели
- Возможность указывать название целевой переменной вручную
- Загрузка произвольных CSV датасетов
- Полноценное сохранение истории в SQLite (модель, параметры, датасет, target_column, accuracy, timestamp)
- Docker + docker-compose

---

### Технологии

- **Backend**: FastAPI + Pydantic
- **Frontend**: Streamlit
- **ML**: scikit-learn
- **БД**: SQLite
- **Контейнеризация**: Docker Compose
